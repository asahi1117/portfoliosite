自己紹介

あさひです。POSSEの活動において、新人ハッカソンでは二位、夏ハッカソンでは一位を獲得しました。

夏ハッカソンでは同じチームの先輩に刺激をもらい、今では熱中して取り組んでいます。 秋ハッカソンでは次は自分が先輩のようにチームを優勝に導いていきたいと思います

スキルリスト

  • HTML

    セマンティックな見出しとセクションで、1ページの情報設計ができます。

  • CSS / Tailwind

    スマホ幅とPC幅の両方で読みやすいレイアウトを組み立てます。

  • JavaScript

    イベント、DOM操作、fetch / async await で画面を更新できます。

  • Git / GitHub

    ブランチとPRで週ごとの提出物を残しています。

  • Splide

    CDNと必須クラスを使って、作品紹介のスライダーを実装できます。

  • GitHub API

    公開APIからユーザー情報を取得し、成功と失敗を画面に分けて出せます。
